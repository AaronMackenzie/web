    What these are

    Standalone single-file exercises: each HTML page has its own script and no libraries. They were written to practise JavaScript basics: strings, arrays, regular expressions, promises, Map/Set, events and browser APIs.

    How they were checked

    Every page was loaded in a real browser with alert and prompt replaced by a recorder, then driven with scripted input (58 checks across the 27 pages). Expected results for the cipher, leap-year, vowel and virus checks were computed separately in Python. The original files passed 39 of the 58 checks; the fixed copies pass all 58.

    Reading the results

    The "Try this" lines are results from that scripted run, so you can compare them with what you see. Timing pages (Map vs Object, Set vs Array) print machine-dependent numbers, so there is no fixed expected value.

    Dialog note. Most pages report their answer with the browser's own alert() and ask for input with prompt(). Some browsers hide those dialogs when a page is shown inside a frame, and the frame cannot show them at all when this page is opened as a local file. If nothing appears, use Open in new tab. The geolocation page needs permission and an https (or localhost) address. This gallery runs entirely in your browser and makes no network requests of its own.
